# practice_odin

A long-term personal dojo for becoming dangerous with the **Odin** programming language.

**Goal:** Gain deep, practical fluency in Odin by building real (if simplified) systems — starting from language core and explicit memory management, through data structures and tools, all the way to a GUI library and a text editor that is used to improve itself and the surrounding tools.

This is deliberately parallel in spirit to `practice_go`, but shaped around Odin’s strengths:

- Explicit allocators and memory discipline from day one
- Heavy use and study of the `core:` library
- Direct systems / Win32 work via `core:sys/windows`
- Data-oriented design and simple, readable code
- Progressive reuse: everything later is built on what you built earlier

The journey is designed for **12–18 months** of steady work. Experience and shippable artifacts matter more than perfection.
