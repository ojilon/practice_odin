# Exercises — Hello and Basics

## Must implement

1. A procedure that returns a greeting string (or prints one).
2. A procedure that takes two integers and returns their sum.
3. A small demonstration that uses both from a runnable entry point.

## Stretch
- Try `fmt.printf` with a few format verbs.
- Declare a constant and a few variables of different integer sizes.

## Notes
No allocator concerns required yet. Focus on package layout and the edit-compile-run loop.
